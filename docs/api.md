# API уведомлений

Источник истины для схем запросов и ответов: код (Pydantic-схемы) и интерактивная документация на `/docs`. Этот файл описывает поведение и правила.

## Эндпоинты

`POST /notifications` принимает сообщение, сохраняет уведомление и outbox-задание одной транзакцией PostgreSQL и возвращает `202 Accepted`, ID и статус `created`.

`GET /notifications/{id}` возвращает текущее состояние уведомления.

При недоступности RabbitMQ API продолжает принимать сообщения: задания остаются в outbox до публикации.

## Аутентификация

Оба метода требуют заголовок `X-API-Key` активного магазина. Ключ сверяется по SHA-256 с `shops.api_key_hash`.

- неверный ключ: `401`;
- чужое или отсутствующее уведомление: `404`.

## Идемпотентность

При создании обязателен заголовок `Idempotency-Key`: от 1 до 128 символов из `A-Z`, `a-z`, `0-9`, `._:-`.

- повтор с тем же ключом и тем же сообщением: `200` и текущее уведомление;
- повтор с тем же ключом и другим сообщением: `409`;
- ключи независимы для разных магазинов.

## Пример

```bash
curl -i http://localhost:8000/notifications \
  -H 'Content-Type: application/json' \
  -H 'X-API-Key: YOUR_STORE_KEY' \
  -H 'Idempotency-Key: order-123-sms' \
  -d '{"channel":"sms","recipient":"+79990000000","body":"Заказ принят"}'
```

## Каналы и поля

| Канал | Поля | Ограничения |
| --- | --- | --- |
| `email` | `channel`, `recipient`, `subject`, `body` | email до 254 символов, тема до 200, текст до 10000 |
| `sms` | `channel`, `recipient`, `body` | номер в формате E.164, текст до 160 символов |
| `push` | `channel`, `recipient`, `title`, `body` | токен до 320 символов, заголовок до 100, текст до 1000 |

Пустые строки и строки из одних пробелов, строки с `U+0000`, лишние поля и некорректные значения возвращают `422`. Исходные строки сохраняются без нормализации.

Push-заголовок хранится в `notifications.subject`, текст в `notifications.content`.

## Что пока не реализовано

Текущая реализация использует целочисленные ID и статусы из моделей БД, без префикса `/api/v1`, биллинга и истории попыток.
